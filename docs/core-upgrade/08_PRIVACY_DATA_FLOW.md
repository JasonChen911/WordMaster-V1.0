# 08 · 隐私与数据流 (PRIVACY & DATA FLOW)

## Local First 原则

- 词库、学习记录、学习历史、FSRS 状态、AI 缓存**全部保存在本地** `%APPDATA%\WordMaster\`。
- 不主动上传数据库、不自动上传学习历史。

## 发送给 AI 服务的数据（最小化）

| 功能 | 发送内容 | 不发送 |
|---|---|---|
| 材料分析 | 用户主动提交的材料片段（截断到 6000 字符） | 完整数据库、系统路径 |
| 学习诊断 | 单个词的最近事件摘要（次数/正确率/混淆词） | 无关历史、用户配置 |
| 例句/练习生成 | 目标词 + 难度/题型 | 用户其它学习数据 |

## API Key 安全

- DeepSeek API Key 存于 **Windows 凭据管理器（keyring）**，不写入源码、不写日志、不回传前端。
- 前端只能拿到「是否已配置」状态，永远拿不到 Key 内容。
- 环境变量 `WORDMASTER_DEFAULT_API_KEY` 仅作批量部署默认值，优先级低于用户自己的 Key。

## 前端 AI 配置页

`设置 → AI 服务` 提供隐私说明：Key 仅存本机、Token 由用户账户承担、例句缓存减少重复调用。

## 未来云同步（如加入）

必须用户**主动开启**，默认关闭；本轮未实现。
