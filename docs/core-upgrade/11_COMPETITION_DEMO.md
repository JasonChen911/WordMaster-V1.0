# 11 · 比赛演示脚本 (COMPETITION DEMO)

> 核心故事：老师发材料 → AI 决定学什么 → 学生学 → FSRS 决定何时复习 → 系统观察 → AI 诊断 → 干预练习 → 洞察变化 → 教师预览。

---

## ⏱ 30 秒版（竖屏）

1. 标题：「老师发了一篇英语材料，学生该背哪些词？」（0-5s）
2. 词库管理 → AI 材料分析 → 示例 →「AI 分析材料」（5-15s）
3. 候选词列表 + 重要度百分比 + 难度标签 → 生成词书 → 开始学习（15-25s）
4. 学习卡片四级反馈 + 结尾 Logo（25-30s）

## ⏱ 60 秒版

| 时间 | 点击/画面 | 讲解 |
|---|---|---|
| 0-8s | 启动 + 首页 | 首页一句话「今天还有 N 个学习任务」，点「开始学习」留到后面，先讲材料 |
| 8-20s | 首页 → AI 材料分析 → 示例 → 分析 | 上传/粘贴文章，AI 提取重点词 |
| 20-35s | 候选词 + 全选 + 生成词书 | AI 给出重要度/难度/理由/标签，人工确认 |
| 35-48s | 开始学习 + 卡片 | 四级反馈，点「为什么今天复习」展示保持率 |
| 48-60s | 分析页 + 教师 Preview + 结尾 | AI 洞察 + 教师预览 |

## ⏱ 90 秒版（重点）

1. **0-10s 痛点**：「背哪些词？何时复习？为什么记不住？」
2. **10-30s AI 材料引擎**：首页 → AI 材料分析 → 示例 → 分析（停顿 2s 看 AI 摘要）→ 候选词 → 生成词书。
3. **30-55s 学习 + FSRS**：开始学习 → 四个按钮（键盘 1-4）→ 作答后看「预计 X 天后复习」→ 点「为什么今天复习」→ 展示保持率/稳定度/遗忘风险（**这里展示 FSRS**）。
4. **55-75s AI 诊断 + 练习**：故意把 economic/economical 答错 2-3 次 → 分析页 → 薄弱词「分析」→ 诊断（易混 economic）→ 生成针对性辨析题 → 作答（**展示 AI 基于真实数据诊断**）。
5. **75-85s Learning Insights**：展示真实 7 天统计 + 错误类型分布 + AI 洞察（**展示真实学习数据**）。
6. **85-90s Teacher Preview**：教师预览 → 班级薄弱词 → AI 教学总结（**展示 Preview，明确标注演示数据**）+ 结尾。

## ⏱ 180 秒版

在 90 秒版基础上展开：
- 材料引擎：演示 TXT/MD/粘贴三种入口 + 本地 fallback（断网时）。
- FSRS：完整讲一遍 again/hard/good/easy 如何改变下次复习。
- 诊断：展示 diagnosis / confused_with / recommended_exercise_type 三个字段。
- 阅读闭环：阅读页点词加入生词 → 复习时展示来源句。
- Teacher Preview：班级完成率/正确率/遗忘率 + 学生名单。
