# 01 · 产品说明 (PRODUCT DESCRIPTION)

## 作品名称

**WordMaster AI** — AI 驱动的自适应词汇学习与教学平台

## 一句话介绍

> 让 AI 决定学什么，让 FSRS 决定什么时候复习。

## 产品概述

WordMaster AI 是一款面向中国高校英语课程、四六级与考研场景的**本地优先**桌面词汇学习平台。它把「背单词软件」从“按固定顺序刷词”升级为一条完整闭环：

```
学习材料 → AI 理解材料 → AI 提取重点词汇 → 生成个性化词表 → 学生学习
→ FSRS 自适应安排复习 → 记录答题行为 → AI 分析错误原因
→ 生成针对性例句/辨析/练习 → 再次学习 → 形成个人学习画像
```

在 WordMaster AI 中，AI 不是聊天机器人，而是**直接参与学习路径的引擎**：它理解材料、提取重点、诊断错因、生成练习；FSRS 则负责“什么时候复习”。两者分工明确，共同构成产品的核心竞争力。

## 目标用户

- 高校英语教师：上传课程材料，AI 自动提取重点词生成课程词表，查看班级薄弱点。
- 备考四六级 / 考研的大学生：从真实材料中建立词表，按遗忘曲线自适应复习。
- 需要针对性突破薄弱词汇的自学者。

## 用户痛点

| 痛点 | WordMaster AI 的解决 |
|---|---|
| “一篇材料里到底该背哪些词？” | AI 材料引擎自动提取重点词汇，忽略 the/have/very 等无效词 |
| “复习时间不科学，不是忘太早就是背太勤” | FSRS 根据每次作答（忘记/困难/一般/简单）自适应计算下次复习 |
| “总记不住这个词，不知道为什么” | 基于真实错误记录，AI 诊断错因并给出辨析与练习 |
| “易混词分不清（economic/economical）” | 易混词系统给出区别、记忆法与双词例句 |
| “老师不知道全班哪里薄弱” | 教师端汇总班级共性薄弱词与高遗忘风险词 |

## 核心功能

1. **AI 材料引擎**：TXT / Markdown / 纯文本 / 粘贴 → AI 提取重点词汇 → 人工确认 → 一键生成词书。
2. **FSRS 自适应复习**：四级反馈（忘记/困难/一般/简单），difficulty / stability / retrievability 状态，可解释的“为什么今天复习”。
3. **AI 学习诊断**：薄弱词的错因分析、易混词辨析、针对性练习生成。
4. **学习分析**：真实统计（7 天学习/复习/正确率/遗忘率）+ AI 洞察 + 高风险词汇。
5. **阅读闭环**：阅读中点击生词 → 加入 FSRS → 复习时展示“你第一次在哪里看到它”。
6. **教师端 MVP**：课程、班级学习情况、共性薄弱词、AI 教学总结。

## AI 的角色

AI 贯穿七个环节：材料理解、重点词汇提取、例句/练习生成、易混词分析、错误原因分析、个性化建议、学习报告。

## AI 为什么不可替代

- AI 能从任意一篇真实材料中判断“哪些词值得学”，这是规则系统做不到的语义理解。
- AI 能基于**真实答题数据**解释“为什么总记不住”，而不是套用固定话术。
- AI 能生成**针对某个学生的具体薄弱点**的练习，而非通用题库。

## FSRS 的作用

FSRS（Free Spaced Repetition Scheduler）解决“什么时候复习”：它维护每个词的三元组
`difficulty / stability / retrievability`，根据用户每次的四级反馈计算下一次复习时间。
WordMaster AI 把 FSRS 做成**可解释**的——用户能看到预计记忆保持率、遗忘风险与下次复习时间。

## 技术架构

React 18 + Vite 前端 → FastAPI 后端 → Learning Engine（FSRS Engine / AI Gateway / Vocabulary Engine / Analytics Engine）→ SQLite（本地）。桌面壳为 PyWebView。详见 `03_TECHNICAL_ARCHITECTURE.md`。

## 创新点

不是“用了 AI”，而是把 **AI + FSRS + 学习行为数据** 组成一个完整自适应学习闭环。详见 `04_INNOVATION.md`。

## 应用场景

- 大学英语课堂：教师上传单元课文 → 生成课程词书 → 学生复习 → 教师查看薄弱点。
- 四六级/考研备考：从真题阅读材料建立个性化词表。
- 自学：从任意英文材料（新闻、论文、教材）构建词表。

## 隐私方案（Local First）

- 词库、学习记录、学习历史默认全部保存在**本地**（`%APPDATA%\WordMaster\`）。
- AI 请求前只发送**完成任务所需的最小内容**（如要分析的几个词），不上传完整数据库或学习历史。
- API Key 存于 Windows 凭据管理器，不写入源码、不回传前端。
- 云同步（若未来加入）必须用户主动开启。

## 未来商业模式

- 面向学校/培训机构的教师端（班级管理、教学报告）SaaS。
- 高级 AI 功能订阅（更丰富的诊断/练习/材料解析额度）。
- 机构定制词库与课程内容合作。
