# 02 · 演示脚本 (DEMO SCRIPT)

> 适合竖屏录制。核心演示线：**老师上传材料 → AI 提取重点词 → 学生学习 → FSRS 安排复习 → AI 分析错误 → 教师看到班级薄弱点**。

---

## ⏱ 60 秒版本（竖屏）

| 时间 | 画面 | 台词（示例） |
|---|---|---|
| 0:00–0:05 | 标题卡 | 「老师发了一篇英语材料，学生到底应该背哪些词？」 |
| 0:05–0:15 | 词库管理 → AI 材料分析 | 打开 WordMaster，粘贴/上传一篇《AI 与教育》短文，点「AI 分析材料」。 |
| 0:15–0:28 | 候选词列表 | AI 自动识别出 20+ 候选词，推荐重点词，忽略 the/have/very。勾选确认。 |
| 0:28–0:35 | 生成词书 → 开始学习 | 一键生成词书，直接进入学习。 |
| 0:35–0:45 | 学习页 | 卡片作答（忘记/困难/一般/简单），FSRS 实时计算下次复习时间，点「为什么」看记忆保持率。 |
| 0:45–0:55 | 学习分析 | 故意答错几个词后，AI 根据真实记录诊断错因、生成练习；易混词 economic/economical 辨析。 |
| 0:55–1:00 | 教师端 + 结尾 | 教师端看到班级共性薄弱词；结尾「WordMaster AI — AI-powered Adaptive Vocabulary Learning」。 |

## ⏱ 90 秒版本

1. **0:00–0:08 痛点**：「老师发材料，学生该背哪些词？复习间隔怎么定？为什么总记不住？」三个问题抛出。
2. **0:08–0:30 材料引擎**：上传文章 → AI 分析 → 候选词（重要度/难度/理由）→ 人工确认 → 生成词书（展示词书自动激活并进入学习队列）。
3. **0:30–0:50 学习 + FSRS**：开始学习，四级反馈按钮；展示「预计 3 天后复习 / 遗忘风险较高」；点「为什么今天复习」展示保持率/稳定度/遗忘风险。
4. **0:50–1:10 AI 学习分析**：故意把 economic/economical 答错；进学习分析，AI 诊断「已连续 3 次混淆」并给出区别、记忆法与双词例句；展示针对性练习。
5. **1:10–1:25 教师端**：教师端显示班级完成率、平均正确率、共性薄弱词（distinguish/distinctive 等）；AI 教学总结引用真实统计。
6. **1:25–1:30 收尾**：一句话定位 + 结尾 Logo。

## ⏱ 180 秒版本（完整版）

### 第一幕 · 痛点（0:00–0:20）
三个真实痛点，逐条放大：「背哪些词」「什么时候复习」「为什么总记不住」。

### 第二幕 · AI 材料引擎（0:20–1:00）
- 完整演示：上传 TXT/MD、粘贴、示例文章三种入口。
- AI 分析过程与结构化输出（word / meaning / importance / difficulty / reason / example）。
- 强调：JSON 校验 + 重试 + 兜底，AI 输出异常不崩溃。
- 人工确认环节（全选/逐个勾选）。
- 生成词书并进入 FSRS。

### 第三幕 · FSRS 学习（1:00–1:40）
- 学习卡片：WORD / phonetic / meaning / example / learning status。
- 四级反馈（忘记/困难/一般/简单）+ 键盘 1-4。
- 「为什么今天复习」：预计记忆保持率、稳定度、遗忘风险、下次复习时间。
- 展示「忘记」会把词拉回短期，「简单」会拉长间隔。

### 第四幕 · AI 学习分析（1:40–2:20）
- 故意答错 economic/economical。
- 学习分析页：真实 7 天统计（学习/复习/正确率/遗忘率/时长）。
- AI 洞察（引用真实数据，非凭空生成）。
- 薄弱词「分析」→ 错因诊断 + 针对性练习。
- 易混词辨析系统。

### 第五幕 · 教师端（2:20–2:50）
- 教师端：演示班级（明确标注演示数据）。
- 班级完成率、平均正确率、遗忘率。
- 共性薄弱词列表 + AI 教学总结。

### 第六幕 · 收尾（2:50–3:00）
- 一句话定位 + 技术架构简图 + 结尾。
